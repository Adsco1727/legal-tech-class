# Notebook Inventory

## Canonical starter

The canonical notebook starter for all future DPO notebook work is:

- NOTEBOOK_TEMPLATE_STANDARD.ipynb

This file is the source of truth. All future notebook work should be created by copying this template or by copying the structure documented here.

## Rule

- Do not modify the canonical template directly for ad hoc work.
- Copy it into a project-specific notebook when starting a new analysis or operational run.
- Preserve the readiness panel, Gate A / Gate B checks, evidence capture, and HITL review sections.

## Copy-me location

Use the companion file in this folder as the copy-ready starter:

- COPY_ME_NOTEBOOK_TEMPLATE.md

## Operational intent

This inventory exists so that:

- future notebooks remain consistent
- operators can find the approved template quickly
- AI and HITL workflows share the same readiness contract
- repo-level governance does not drift into ad hoc notebook creation
