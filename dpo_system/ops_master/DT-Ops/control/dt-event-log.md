# DT Event Log

## Purpose
Capture operator events, checkpoints, and notable transitions during execution.

## Log Format
- Timestamp
- Event name
- Status
- Notes
- Evidence reference

## Example Entries
- 2026-08-05 09:00 — Intake confirmed — OK — Source files present
- 2026-08-05 09:15 — Pipeline started — OK — Execution launched
- 2026-08-05 09:30 — Evidence captured — OK — Manifest updated
