# Operator Cockpit (Wave 4)

Read-only Streamlit dashboard for LAW LAB control-plane visibility.

## Run

From repo root:

```powershell
.venv\Scripts\python.exe -m streamlit run dpo_system/dashboard/streamlit_app.py
```

## Boundaries

- Read-only dashboard
- No ingestion execution
- No external API calls
- No outbound automation
